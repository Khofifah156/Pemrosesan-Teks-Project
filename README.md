# Penyaringan Email Spam dengan Algoritma Naive Bayes

Project ini membahas klasifikasi email berbahasa Indonesia untuk membedakan email spam dan non-spam menggunakan algoritma Multinomial Naive Bayes. Data teks melalui tahap preprocessing, seperti case folding, filtering, tokenisasi, dan stopword removal, sebelum diubah menjadi fitur menggunakan TF-IDF dan Bag of Words.

Kedua metode representasi fitur kemudian dibandingkan berdasarkan hasil evaluasi model menggunakan accuracy, precision, recall, f1-score, dan confusion matrix. Model juga digunakan untuk melakukan prediksi pada data email baru.
